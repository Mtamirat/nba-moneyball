# NBA Moneyball – Player Valuation & Roster Optimization Engine

## Project Overview

The NBA Moneyball Player Valuation & Roster Optimization Engine is a relational database project designed to evaluate NBA players based on their individual performance compared to their salaries.

The goal is to help a basketball front office identify undervalued players, evaluate player efficiency, and make better roster decisions while staying within a salary cap.

## Project Objectives

- Store NBA player information and statistics.
- Track player salaries across different seasons.
- Evaluate player performance using statistical metrics.
- Compare player production against salary costs.
- Identify undervalued and cost-efficient players.
- Support roster decisions under a salary cap.
